# Claude Skills, Curated

Two Top 20 lists of Claude skills, ranked by outcomes, not checklists. Updated every Saturday.

- [Engineering Top 20](engineering/README.md): skills that help a software engineer ship more, ship better, debug faster, and waste less time and fewer tokens.
- [Finance Top 20](finance/README.md): skills that help a retail investor and trader make better decisions and better risk-adjusted returns.

## How we rank

Textbook criteria (clean README, installs fine, maintained) only get a skill through the door. The ranking itself is outcome-based: what does this skill actually do for the person using it? Evidence means benchmarks, head-to-head tests, real adoption, documented before-and-after. When the evidence is thin, we say so plainly and rank it down. No skill is ranked on promises.

## The archive rule

Every skill we evaluate gets an entry in its category archive, in or out: in the list, dropped, watchlist, or rejected, with a date and a reason. The only things that skip the archive are trash: dead repos with no README, broken installs, spam. Anyone browsing sees the full picture.
